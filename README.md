# Lab Sheet Reader

시험 기기가 뽑은 인쇄물을 스캔해서 읽고, 스스로 검증한 뒤,
정보시스템에 붙여넣을 수 있는 형태로 건네주는 도구.

```text
스캔 PDF  →  판독  →  검증  →  그리드  →  클립보드  →  붙여넣기
```

## 무엇을 없애려는 건가

시험 기기는 결과를 화면에 엑셀로 띄운다. 그런데 그 기기에 붙은 컴퓨터는
보안 때문에 인터넷도 USB도 막혀 있어 파일을 꺼낼 수 없다.
그래서 인쇄하고, 종이를 보며 손으로 다시 입력한다.

완벽한 디지털 데이터가 종이와 사람 손을 거쳐 다시 디지털이 된다.
정보가 좋아지는 구간은 없고, 나빠지는 구간만 있다.

이 도구는 종이와 사람 손 사이에 카메라를 끼워 넣는다.
보안 격리는 그대로 두고, 이미 나오는 인쇄물을 대신 읽는다.

## 어떻게 믿을 수 있나

읽는 것보다 **읽은 게 맞는지 확인하는 쪽이 어렵다.**
표에서 한 줄이 밀려 읽히면 모든 값이 엉뚱한 시료에 붙는데,
값 자체는 전부 정상 범위라 어떤 규칙에도 걸리지 않는다.

그래서 실험 배치에 원래 들어있는 품질관리 시료를 앵커로 쓴다.

```text
세척수     값이 0 근처여야 한다
표준품     값이 알려진 농도 근처여야 한다
```

표준품 자리에서 0.1이 읽혔다면 한 줄 밀린 것이다.
외부 대조 자료 없이 판독 결과를 스스로 검증한다.

## 원칙

```text
정확성   모르면 모른다고 한다.  억지로 읽지 않는다
절제     헛경보가 잦으면 아무도 안 본다.  적게, 확실하게
무침습   기존 절차와 보안을 건드리지 않는다.  한 단계만 끼워 넣는다
투명성   왜 그렇게 읽었는지 원본으로 확인할 수 있어야 한다
```

## 시작하기

```powershell
npm install
copy .env.example .env.local   # ANTHROPIC_API_KEY 채우기
npm run dev
```

자세한 것은 [docs/SETUP.md](docs/SETUP.md).
