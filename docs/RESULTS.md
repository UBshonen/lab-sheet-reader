## 2026-08-28 · 첫 판독

기기 결과표 사진 한 장. 사진이라 스캔보다 조건이 나쁜데도 통과했다.

```text
모델      gemini-3.6-flash
입력      사진 1장 (JPG, 3.0MB)
시간      41.7초
토큰      입력 1,318 · 출력 3,357
비용      유료 기준 약 19원.  무료 티어라 실제 청구는 없음
```

### 결과

```text
읽은 행       24행 — 표의 전부
애매한 셀      0개
값 정확도      24/24
```

시험기록부와 교차 검증했다. 네 시료 모두 일치.

```text
              판독      기록부의 계산식
A 유입         4.337    (4.337-0)*1
A 유출         5.759
B 유입         2.550    (2.55-0)*1
B 유출         2.457    (2.457-0)*1
```

### 정렬 자가검증이 작동했다

이게 이번 회차에서 제일 확인하고 싶던 것이다.

```text
표준품 3개     5.171 · 5.188 · 5.165    모두 5 근처.  통과
세척수 8개     0.007 ~ 0.099            모두 0 근처.  통과
바탕시료 1개    0.01188                  통과
              14개 전부 제자리
```

표가 한 줄 밀려 읽혔다면 표준품 자리에 `0.05135` 가 왔을 것이다.
5 근처가 나왔다는 것이 곧 정렬이 맞다는 증거다.

**성적서도 기록부도 없이, 문서 하나만으로 스스로 판정했다.**
입력 전 검증이 가능하다는 설계 전제가 실물에서 확인되었다.

### 지시문이 먹혔다

```text
검량선 페이지를 넣었더니   "결과표가 없다" 고 손을 들었다.  억지로 읽지 않음
값이 애매한 자리          지어내지 않고 null 로 두었다
```

### 이번 회차에서 정해진 것

```text
애매한 셀이 0개        인쇄물은 거의 안 나온다
                      → 확인 화면을 크게 만들 필요가 없다
행 수 24행            드래그로 순서를 바꿔도 감당된다
                      → 별도 정렬 방법이 아직 필요 없다
응답 41.7초           기다리는 화면이 필요하다.  즉시 응답이 아니다
```

### 남은 확인

```text
손글씨 일지 (BOD·SS)    인쇄물과 난이도가 다르다.  아직 안 해봄
T-N · T-P 출력          지명이 생략된 "유출" 행이 있다.  아직 안 해봄
같은 파일 반복 실행       매번 같은 값이 나오는지
다른 회차 자료           한 장만으로는 판단할 수 없다
```

## 2026-08-28 · 뭉치 전체

접수번호 한 건의 11장을 폴더째 넣었다. 사진이라 스캔보다 조건이 나쁘다.

```text
모델      gemini-3.6-flash
입력      사진 11장
호출      판별 11 + 판독 3
토큰      입력 21,979 · 출력 13,350
비용      유료 기준 약 93원  ← 뭉치 하나당
```

### 분류 11/11

```text
건너뜀   공문 · 시험성적서 · 시험기록부 2 · 검량선 4      8장
읽음     현장측정기 · TOC 결과 · T-N·T-P 결과           3장
```

판별이 갈라주므로 **읽지 않을 8장에는 판독 호출이 나가지 않는다.**
판별을 붙였는데도 비용이 오히려 준다.

### 값 교차 검증 — 시험기록부와 대조해 10개 모두 일치

```text
                판독      기록부
현장측정기 pH     7.49  →  7.5        1자리 반올림
현장측정기 DO     7.65  →  7.7
TOC            2.550  →  (2.55-0)*1
T-N           2.0854  →  2.0854*1    그대로
T-P           0.0339  →  0.0339*1
```

문서에 적어둔 자릿수 규칙이 실물과 맞는다.

### 걱정하던 두 가지가 확인됐다

**지명 없는 "유출" 행**

```text
66  A 유입    4.4388
67  유출      0.5936     ← 지명 없음
68  B 유입    2.0854
69  유출      1.3059     ← 지명 없음
```

추측해 채우지 않고 보이는 그대로 읽었다. 어느 지점으로 붙일지는
사람이 화면에서 정한다.

**문서에 인쇄된 정답으로 검증**

자동분석기 출력의 `Ref./Target` 열을 읽어 측정값과 맞춰보는 규칙이
작동했다. STD 1~6 이 모두 통과. 정렬이 밀리면 여기서 즉시 걸린다.

```text
        T-N      기준
STD 1   0.0660   0.0600
STD 5   5.0758   5.0000
STD 6   9.9594  10.0000
```

### 남은 손질

```text

표시 잘림      기준값 "0.0000 - 0.0000" 이 화면에서 잘린다
수기 일지      이번 뭉치에 없었다. BOD·SS 는 아직 안 해봄
```
