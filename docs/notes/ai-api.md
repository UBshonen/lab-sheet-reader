# AI API 와 요금

> 이 도구가 무엇에 돈을 쓰는지, 지금은 왜 공짜인지, 나중에 얼마가 드는지.
> API 를 처음 듣는 사람에게 설명할 수 있도록 쓴다.

---

## 1. 배경 — API 가 왜 생겼나

사람이 AI 를 쓸 때는 홈페이지에 들어가 글을 치고 답을 받는다.
그런데 **프로그램이 AI 를 쓰려면** 그 방법으로는 안 된다.
프로그램은 홈페이지를 눈으로 보고 손으로 타이핑하지 못한다.

그래서 회사들이 **프로그램 전용 창구**를 따로 열어두었다. 이것이 API 다.

```text
사람   →  홈페이지에 글을 친다        →  화면으로 답을 본다
프로그램 →  API 로 데이터를 보낸다     →  데이터로 답을 받는다
```

없던 시절에는 회사마다 AI 를 직접 만들어야 했다. 지금은 창구에 요청만
보내면 되고, 만드는 쪽은 회사가 맡는다.

> **용어** — API 는 Application Programming Interface 의 줄임말이다.
> 우리말로 하면 "프로그램끼리 주고받는 창구" 정도다.

---

## 2. 원리 — 요금은 글자 수로 매긴다

전기요금이 쓴 만큼 나오듯, AI 요금도 **주고받은 양만큼** 나온다.
단위는 글자가 아니라 **토큰**이다.

```text
토큰   AI 가 글을 잘게 쪼갠 조각
       영어는 단어 하나가 대개 토큰 하나
       한글은 글자 하나가 토큰 하나에서 두 개쯤
       사진은 넓이에 비례해 토큰으로 환산된다
```

> **비유** — 택배 요금이 무게로 매겨지는 것과 같다. 보내는 짐과 받는 짐을
> 각각 재서 합산한다.
>
> **안 맞는 지점** — 택배는 왕복 요금이 같지만, AI 는 **받는 쪽이 다섯 배쯤
> 비싸다.** 만드는 데 힘이 더 들기 때문이다.

우리가 쓰는 모델의 값은 이렇다.

```text
gemini-3.6-flash    보낼 때 100만 토큰에 $0.75
                    받을 때 100만 토큰에 $3.75
```

100만 토큰은 감이 안 잡히는데, 우리 실측으로는 이렇다.

```text
사진 한 장 보내기        약 1,300 토큰
표 24행 읽어서 받기      약 3,400 토큰
합쳐서                  약 19원
```

## 3. 용어

```text
API          프로그램이 AI 에게 일을 시키는 창구

토큰         요금을 매기는 단위. 글을 잘게 쪼갠 조각
             보내는 토큰(입력)과 받는 토큰(출력)을 따로 센다
             출력이 다섯 배쯤 비싸다

모델         AI 의 종류. 자동차 모델명 같은 것
             큰 모델은 똑똑하고 비싸고 느리다
             작은 모델은 덜 똑똑하고 싸고 빠르다

API 키       창구를 쓸 때 내미는 신분증
             이게 있어야 요청이 받아들여지고, 이 키로 요금이 매겨진다
             남에게 알려주면 남이 쓴 요금이 나에게 청구된다

무료 티어     돈을 안 내고 쓸 수 있는 구간
             대신 하루에 몇 번 이라는 제한이 붙는다

레이트 리밋   1분에 몇 번, 하루에 몇 번 까지만 허용하는 제한
             넘으면 잠시 거절당한다. 기다렸다 다시 보내면 된다
```

## 4. 실무 — 지금 우리는 무료다

### 왜 공짜인가

Google 은 **카드 등록 없이 쓸 수 있는 무료 구간**을 열어두었다.
우리는 개인 구글 계정으로 키를 발급받았고 **결제 수단을 연결하지 않았다.**

```text
Google Cloud 프로젝트를 만들었다   →  이것만으로는 과금되지 않는다
결제 계정을 연결하지 않았다        →  그래서 무료 구간에 머문다
```

화면에 찍히는 `약 19원` 은 **유료로 갔다면 얼마인지**를 미리 보여주는 것이고,
지금 실제로 청구되는 금액은 **0원**이다.

### 무료의 대가

공짜에는 대가가 있다.

```text
무료 구간   보낸 내용이 AI 개선에 쓰일 수 있다. 사람이 검토할 수도 있다
유료 구간   쓰이지 않는다
```

그래서 **무료로 쓰는 동안에는 공개해도 되는 자료만 넣는다.**
개인정보가 들어간 문서는 유료로 전환한 뒤에 넣는다.

다행히 이 도구는 **기기 출력물만 읽고 성적서·시험기록부·공문은 읽지 않는다.**
담당자 이름과 접수번호는 그 세 문서에만 있으므로 설계상 나가지 않는다.

### 얼마나 쓸 수 있나

```text
1분에 몇 번, 하루에 몇 번
개발하며 시험하기에는 충분하다
```

정확한 숫자는 계정마다 다르고 자주 바뀌므로, AI Studio 의
사용 한도 화면에서 확인한다.

### 유료로 가면 얼마인가

실측 기준이다.

```text
뭉치 한 건 (문서 13장)     약 185원
월 50건                   약 9,000원
월 200건                  약 37,000원
```

### 돈이 새지 않게 하는 장치

```text
캐시          같은 파일을 다시 넣으면 API 를 부르지 않는다
              화면을 고치는 동안에는 아예 호출이 안 나간다

판별 후 건너뛰기  읽지 않을 문서에는 판독 요청을 보내지 않는다
              13장 중 8장이 여기서 걸러진다

사용 한도      콘솔에서 월 상한을 걸어두면 사고가 나도 거기서 막힌다

키를 서버에만   브라우저 코드에 키를 넣으면 남이 가져다 쓰고
              요금은 나에게 청구된다
```

> 매겨집니다. 출력 토큰이 입력보다 다섯 배쯤 비싸요.
>
> 지금은 Google 의 무료 구간을 쓰고 있어서 실제 청구는 0원입니다.
> 카드를 연결하지 않았고, 연결해야만 유료로 넘어갑니다. 대신 무료 구간은
> 보낸 내용이 학습에 쓰일 수 있어서, 지금은 공개 가능한 자료만 넣습니다.
>
> 유료로 전환하면 뭉치 하나에 200원 안팎입니다. 월 50건이면 만 원이 안 됩니다.

> 것만으로 3분의 1이 절약됩니다.
